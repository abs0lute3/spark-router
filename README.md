## How it fits together

```
loadstring(game:HttpGet(".../boot.lua"))()
  -> boot.lua (PLAIN ~1KB micro-stub) fetches boot.enc, decrypts ~3KB instantly, runs it
    -> boot fetches Router.enc, decrypts ~4KB instantly, runs it
      -> router (sealed) detects the game, fetches the PLAIN payload, runs it
```

| File | What it is |
|---|---|
| `boot.lua` | Plain micro-stub. Holds the boot URL + key. Regenerated by `push.py seal` — never hand-edit. |
| `boot.enc` | Encrypted boot. Repo browsers see ciphertext. Generated by `push.py seal` — never hand-edit. |
| `boot.src.lua` | Boot source of truth (commentless). Edit this, then `seal`. |
| `Router.enc` | The encrypted router. Repo browsers see ciphertext. Generated by `push.py seal` — never hand-edit. |
| `Router.src.lua` | The router source of truth (commentless). Edit this, then `seal`. |
| `payloads/dandy-v1.lua` | Plain DandyHub. Same filename = same URL forever. |
| `payloads/bike-v1.lua` | Plain bike script. Same filename = same URL forever. |

| Game | Universe (GameId) | Main PlaceId | Behavior |
|---|---|---|---|
| Dandy's World | 5569032992 | 16116270224 | Notification, fetch latest plain payload, execute |
| Bike Universe | 10768284407 | 98628861455414 | Notification, fetch latest plain payload, execute |
| Anything else | — | — | "Unsupported game" notification, stops |

Payloads are plain on purpose: zero client-side decrypt of big files, so loading is as fast as running source. The encryption lives on the boot + router instead. Anyone holding the loadstring can unwrap both layers, so this is obfuscation, not DRM.

## Updating a payload (for AI agents)

```bash
cd "Push (Read this for AI agents)"
python push.py publish dandy-v1 ../DandyHub.lua   # or: push.bat publish dandy-v1 ..\DandyHub.lua
cd ../SparkRouter
git add payloads/dandy-v1.lua
git commit -m "update dandy-v1"
git push
```

No reseal needed — payload URLs never change.

## Editing the wiring / rotating keys (for AI agents)

```bash
cd "Push (Read this for AI agents)"
# edit ../SparkRouter/Router.src.lua or boot.src.lua first, then:
python push.py seal            # or --rotate for fresh keys, --key / --boot-key individually
cd ../SparkRouter
git add Router.enc boot.enc boot.lua
git commit -m "reseal"
git push
```

The loadstring never changes — `boot.lua` lives at a static URL.

## The loadstring (what users execute)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/abs0lute3/spark-router/main/boot.lua"))()
```
